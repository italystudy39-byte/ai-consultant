# Block Blast · Neon Garden

Игра на HTML, CSS и JavaScript без зависимостей. Откройте `index.html` в браузере.

Поле 8 × 8, три фигуры за раунд, очистка полных рядов и столбцов. Перетаскивание мышью и пальцем, а также выбор фигуры и нажатие на клетку. Рекорд сохраняется локально в браузере. Вращения нет. За каждый блок начисляется 10 очков, за линию — 100; последовательные ходы с очисткой дают множитель. Игра заканчивается, когда ни одну оставшуюся фигуру нельзя разместить.

Анимации размещения, очистки, счёта, возврата фигуры и окончания игры. Поддерживается системная настройка уменьшения движения.

Исходные HTML/CSS переработаны; отсутствующий исходный script.js восстановлен, поэтому точное совпадение прежней логики начисления очков не гарантируется.
